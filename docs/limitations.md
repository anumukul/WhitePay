# Current limitations

No verified live chain queries, token decimals, permit/EIP-3009 capability, zero-WBT settlement, contracts, backend, database, SDK, UI, webhooks, deployment, or npm publication exist yet.

Docker CLI is installed locally but its daemon was unavailable during Step 00. Integration tests will require an isolated running database. Existing-wallet signing is the initial proposed path; embedded wallet compatibility remains unproven.

Testnet tokens have no claimed monetary value. Refunds, recurring billing, bridging, World ID, and mainnet are excluded.
