# Changelog

## 0.1.0-alpha.0

Initial Whitechain Sepolia testnet release. Server-side session, product, price,
merchant and payment APIs; customer-authorized Node HTTP and Fetch checkout
bridges; strict webhook signature/freshness/schema verification; typed errors,
response timeouts and credential-safe redirect handling.

Requires a configured WhitePay API and merchant-side customer authorization.
This package does not sign or broadcast blockchain transactions.
