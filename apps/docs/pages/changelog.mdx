# Changelog

## SDK 0.1.0-alpha.0

Both @whitepay/node and @whitepay/react are public on npm. Release files include compiled ESM and declarations, README, MIT license and changelog. Registry integrity matches the reviewed archives. Fresh consumer runtime, type and Chrome smoke checks pass.

Node provides merchant checkout, products/prices, payment retrieval, typed API errors, webhook verification and authenticated merchant-server bridges. React provides canonical quote review, two authorization signatures, safety cutoff/account/chain checks and confirmed-receipt UI.
